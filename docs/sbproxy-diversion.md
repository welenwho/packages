# TUN 接管与大陆白名单域名分流

SBProxy 仅保留 TUN 接管方式，继续保留大陆白名单、自定义路由、全局三种路由模式。
不移除自适应路由、URLTest、Tailscale 或入口接口绕过功能。`ip-full` 保留，增加
`kmod-nft-queue` 显式依赖。安装迁移删除旧 TProxy 配置字段，只清理能够确认属于
旧 SBProxy 实例的 TProxy 策略规则，不清空共享路由表，也不修改 Tailscale table 52。

## 大陆白名单分流组

在客户端路由设置添加分流组，支持名称、启用、排序、域名列表和目标节点。
目标可以为直连、主节点（包括主 URLTest）或已有节点。分组以 UCI 列表保存，
不再把匿名 section ID 与外部文本文件绑定。节点失效默认报告配置错误，不擅自换出口；
用户也可明确选择回退主节点。

有点的条目匹配域名后缀，无点的条目匹配关键词；转小写、去重并忽略 `#` 注释。
跨组重复、父子域、关键词重叠允许存在，会记录告警，按列表先后顺序匹配。
设备/IP/MAC/入口绕过及端口限制优先于域名组；域名组优先于普通直连/代理名单和地理规则。
启用关键词组时禁用会抢先绕过的 GeoIP 快速路径，待嗅探后按组顺序判断。

各代理出站使用自己的 DNS detour，同一出站的多个组复用解析器；直连组用 WAN DNS。
自定义路由和全局模式不加载这些组，原有规则、节点绑定接口和 DNS 配置保持独立。
这不是对现有自定义路由配置的自动转换。

## 统一地理资源

中国 IP 资源统一为 `geoip_cn.srs` 和 `geoip_cn.ver`，SRS 同时含 IPv4/IPv6。
仍保留 IPv6 开关，不是删除 IPv6 支持。
数据源改为 SagerNet/sing-geoip 的规则集分支（此前为 Loyalsoldier/surge-rules）；
因此除格式变化，也可能存在 IP 分类差异。域名资源仍使用 SagerNet/sing-geosite。

路由器下载后先用已安装核心反编译校验，安装失败恢复旧数据和版本文件。
CI 使用与 sing-box/Makefile 锁定版本一致、经过 SHA-256 校验的上游工具解析资源；
该工具仅用于校验，绝不替代包含本项目 Tailscale 补丁的路由器核心。

Hysteria v1 要求正数上下行带宽，缺少参数的订阅节点跳过；保留既有订阅失败保护。
Hysteria2 的可选带宽和拥塞控制不受影响。Naive 非 TCP 入站在界面中要求 TLS。
